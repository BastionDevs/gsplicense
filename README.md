### Definitions
- **Package**: Refers to the software, including source code, documentation, and associated materials.
- **Author(s)**: The individuals or entities responsible for creating the software package.
- **Legal Purposes**: Usage that complies with applicable laws and regulations.
- **Distribution**: The act of copying and providing access to the software package.
- **Modified Versions**: Alterations made to the original software package.
- **Derivative Works**: New creations based on the original software package.
- **Patent Rights**: Legal rights protecting inventions from unauthorized use.
- **Source Code**: Human-readable instructions that make up the software package.
- **Contributing**: Offering improvements or enhancements to the software project.
- **Warranty Disclaimer**: Statement indicating that the software is provided without guarantees.
- **Modification of Terms**: Bastion SDG's right to change licensing terms at any time.
